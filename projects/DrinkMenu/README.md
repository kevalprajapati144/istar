# Drinks Management System

Trending drinks e-commerce demo: HTML, CSS, JavaScript and Bootstrap 5.3.9 (CDN).

- `index.html`: customer shop (search, categories, sorting, trending, wishlist, quick view, cart, coupons FIRST10 / SAVE50, free-delivery bar, checkout, order tracking).
- `admin.html`: admin panel (demo password `admin123`): dashboard, add / edit / delete drinks, manage orders.
- Data lives in the browser (localStorage). For real use, move data and login to a backend (e.g. Laravel + MySQL).

Run: open `index.html` (internet needed for Bootstrap and fonts). Publish: upload this folder to GitHub Pages.
